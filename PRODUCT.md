# Tumacro

## Platform

Windows desktop, C# and WinForms, x64, .NET Framework 4.8.

## Product purpose

Tumacro maps two mouse thumb buttons to independent copy/paste steps. One captures path text or copied file paths; the other sends Ctrl+C and Ctrl+V. Users can also configure the wheel click and keyboard macros. It runs in the system tray, supports Windows sign-in startup, and offers Swedish and English interfaces.

## Current design scope

The October 20, 2026 request replaces the application icon. The user explicitly chose recognition of the mouse-macro function over recognition of the product name. The application interface, macro behavior, settings, language support, and startup behavior stay within their existing design.

## Icon commitments

Use a distinctive mouse silhouette and two readable thumb controls. Favor a small set of deliberate shapes, generous negative space, and legibility at Windows tray and desktop sizes. The rejected predecessors were a thin oval and a letter T with an arrow badge. Avoid both motifs.
