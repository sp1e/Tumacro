# Tumacro

## Platform

Windows desktop, C# and WinForms, x64, .NET Framework 4.8.

## Product purpose

Tumacro maps two mouse thumb buttons to independent copy/paste steps. One captures path text or copied file paths; the other sends Ctrl+C and Ctrl+V. Users can also configure the wheel click and keyboard macros. It runs in the system tray, supports Windows sign-in startup, and offers Swedish and English interfaces.

## Current design scope

The October 21, 2026 request redesigns the native Studio interface around a physical mouse diagram, live next-action readouts, and a shared overview for mouse assignments and keyboard macros. The user chose Apple interface restraint and Teenage Engineering instrument character, with light/dark/system themes and Swedish/English controls. Preserve the selected application icon, background operation, sign-in startup, and the independent copy/paste workflows while improving macro editing and recorder behavior and resolving clipboard failures. The icon retains the October 20 decision to identify the mouse-macro function through its silhouette and two thumb controls.

## Icon commitments

Use a distinctive mouse silhouette and two readable thumb controls. Favor a small set of deliberate shapes, generous negative space, and legibility at Windows tray and desktop sizes. The rejected predecessors were a thin oval and a letter T with an arrow badge. Avoid both motifs.
