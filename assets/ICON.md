# Tumacro icon

The current icon uses a white T and a mint arrow on a violet rounded square. It replaces the former oval mouse drawing.

`Tumacro.ico` includes 16, 24, 32, 48, 64, 128, and 256 pixel images. The build embeds this file in the executable; the window and tray use the embedded icon. `Tumacro-icon.png` is a preview, and `Tumacro.svg` contains the vector geometry.

The icon was drawn from vector geometry for Tumacro. It uses no stock image or external artwork.
